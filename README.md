# Wachenröder Addendum

Not gonna write a huge fancy ReadMe for this one, but I'll at least tee up the patch:

Wachenröder Addendum is a patch for the recent Wachenroder translation that fixes a bunch of issues. I don't have time to find and work with a translator to deliver an revision of the text, but I can at least bring my graphic design skills to improving some things with the current translation patch. 

The following changes have been made:

Fonts
- Redraw of primary font at 8 x 12 using a Georgia base, and dialogue re-wrapped to fit. New font also applies to: narration scenes, extras galleries, save/load screens, and more
- Item and part descriptions use a new small font with proper descenders
- Proportional font applied to: status screen/HUD/battle menu/battle banter scenes
- Centering and alignment fixed throughout

Graphics
- Cleanplated and removed JP from chapter title and location cards, leaving only background and German
- Actually translated and redrew the end credits (matched with MobyGames)
- Translated and redrew Save Warning screens

Bugs
- Fixed original game bug where months 10–12 would show as "0:", "0; or "0<"
